# موقع أذكار الصباح والمساء 📿

موقع عربي أنيق لأذكار الصباح والمساء الصحيحة بمصادرها، مع مسبحة إلكترونية.

## المميزات
- ✅ جميع الأذكار صحيحة وبمصادرها (البخاري، مسلم، أبو داود، الترمذي)
- 🎨 تصميم جميل وأنيق وسهل
- 🔠 تكبير وتصغير الخط
- 🌙☀️ الوضع الليلي والنهاري
- 📖 خط Traditional Arabic
- 📿 مسبحة إلكترونية بعدة أذكار وأهداف
