# صور موقع العمرة 🕋

جميع الصور من **ويكيميديا كومنز** برخص حرة (CC BY-SA / CC BY):

- `home.svg` — رسم توضيحي: أسرة مسلمة بالأزياء السعودية تتجه إلى مكة (من تصميم الموقع)
- `miqat.jpg` — مسجد ذي الحليفة، ميقات أهل المدينة (أبيار علي)
- `haram.jpg` — المسجد الحرام والطواف ليلاً
- `tawaf.jpg` — الطواف حول الكعبة
- `safa.jpg` — ممر المسعى بين الصفا والمروة
- `zamzam.jpg` — حاج يحلق رأسه (التحلل من الإحرام)

تظهر الصور تلقائياً في أماكنها بالموقع. يمكن استبدال أي صورة بملف آخر يحمل نفس الاسم،
أو إضافة صورة من الجهاز مباشرة بزر "📷 أضف صورة" داخل الموقع.
